# .github

Public configuration repository for the MuseCanto organization.

- `profile/README.md`: the profile shown on the organization home page.
- `profile/assets/`: brand files used by that profile.
  - `hero.webp`: home hero. Ink ground, wordmark, manuscript card, and the line "AI-native creation, then publish." Colors come from musecanto.com.
  - `ribbon.svg`: slogan ribbon, outlined in Source Serif 4. Peach `#E18D61` is the dark-theme primary from the site.
  - `musecanto-wordmark-light.svg` / `musecanto-wordmark-dark.svg`: wordmark for dark and light grounds, outlined from Source Serif 4 Semibold. Change the typeface at the source, then export again.
  - `musecanto-mark.svg`: quill mark, filled with the same peach.

The logo, wordmark, and other brand assets are for official MuseCanto use. This repository does not release them under an open-source license.
